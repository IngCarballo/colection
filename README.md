## 🛠️ Cómo agregar o actualizar un equipo

1. Crear o modificar la ficha individual dentro de la carpeta `pcs/`.
2. Colocar las imágenes en la carpeta `images/<slug-equipo>/`.
3. Mantener actualizada la tabla del `README.md` principal.
